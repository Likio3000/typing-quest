# Project Agent Rules

## Persistent Memory (Required)

- `dev-notes/` is mandatory project memory for this repository.
- At the start of implementation work, read:
  - `dev-notes/project-brief.md`
  - `dev-notes/active-decisions.md`
- Before declaring a task complete, update affected `dev-notes/` files and append a concise entry to `dev-notes/session-journal.md`.

## Skill Usage (Required)

- Use `skills/typing-game-memory/SKILL.md` for all implementation tasks in this repo.
- Keep the memory skill and `dev-notes/` aligned with current behavior.
- If notes and code disagree, treat code as source of truth and update notes in the same task.

## Scope

- These rules are for development workflow only, not runtime game behavior.
